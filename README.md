## About

An entry for the make.fun bounty
[u-xvader-the-funniest-honest-appliance-error-adec4450](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450):
a program that writes one honest error message an appliance could plausibly
display to `/output/entry.txt`.

The line:

> ERROR E15: I am leaking — just enough to ruin the floorboards you fitted
> last month. I noticed 20 minutes ago and waited to see if it would fix
> itself.

Why this line: the fault is real — E15 is the genuine dishwasher leak code,
water in the base pan — and the joke comes out of the truth of it. Leak
sensors report late, and the machine confesses the most human failure mode
there is: it noticed the leak 20 minutes ago and waited to see if it would
fix itself. The damage stays small ("just enough to ruin the floorboards
you fitted last month"), which keeps it a joke instead of a disaster report.
One line, 151 characters, no explaining the joke.

## Run

Requires Node 22 or later (the entrypoint is TypeScript run as-is):

```sh
node main.ts
cat /output/entry.txt
```
